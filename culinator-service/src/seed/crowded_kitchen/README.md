# Crowded Kitchen — Better Than Store Bought

These 96 `.cg` recipes came from Crowded Kitchen's [Better Than Store Bought](https://www.crowdedkitchen.com/category/better-than-store-bought/) category on October 1, 2026. Each file names Crowded Kitchen, credits the recipe, and links to its original page. The category's roundup article was excluded because it is not a standalone recipe.

The source pages' structured recipe data supplied the ingredient lines and method steps. Those lines remain text in the DSL, so Culinator can display them but cannot reliably scale their amounts or derive a detailed schedule. Published total times are included where available. Refer to the linked originals for updates and additional notes.

`culinator-service/src/state.rs` seeds these into their own book on a new, empty catalog. They are separate from the Sample Recipes book.
